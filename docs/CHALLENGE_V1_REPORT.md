## 冻结决策

从本报告提交起，`data/challenge_v1.json` 作为冻结测试集，不再增删或改写。LangGraph
和后续自研 Runtime 必须读取同一文件，使用同一确定性工具、故障注入、最大重试次数和
`matches_expected` 评分器。开发选择只能使用 development 数据，不得针对这24条调 Prompt、
正则、路由或策略。

开放世界语言。
