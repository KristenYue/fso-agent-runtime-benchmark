# Challenge v1 评测协议冻结记录

- 挑战集：24条，6类各4条；结构化语义键唯一。
- 六类：跨句表达、隐式单位、冲突约束、一次性语义污染恢复、持续语义污染、
  间接缺参表达。
- 规则解析器冻结点：`1b7b97d`；挑战集建立后不得为挑战表达补正则。
- 唯一主指标：严格任务通过率，包括状态、最终配置 ID 和要求的轨迹事件。
- 次指标：参数完全解析率、按挑战类型任务通过率。
- Oracle 门禁：24/24；否则说明任务 ground truth 或执行器错误，不运行后续 Agent。
- 判定：规则基线低于 Oracle 仅证明受控规则的边界，不自动证明 LLM Agent 更好；
  LangGraph 必须在同一冻结集上提高通过率且不增加约束违反或错误恢复。
- 轨迹要求：语义污染任务必须记录 `semantic_error`；一次性污染还必须记录恢复来源，
  防止最终选择碰巧相同而获得通过。
- 诚实性说明：实现测试在正式结果留档前验证了 Oracle 能通过且规则存在边界；
  因此本记录不是对规则结果完全盲化的统计预注册，不作显著性推断。
