- 源码提交：`be758b0f3c6f6cc95432bc3b9fd6ed5289043854`；
- 模型调用和网络调用：均为0。

## 任务构成

- 18条成功规划，其中3条包含“阈值目录首次超时、第二次成功”；
- 6条缺少必要参数，期望明确追问；
- 3条数据充分但没有已验证可行配置；
- 3条阈值目录在重试预算内持续不可用，期望 `tool_error`。

## 结论

五步执行、缺参追问和有限重试的契约已经可执行、可评分，但当前模板仍能被规则完整解析。
因此仍不能声称 Agent 带来收益，更不能因任务名含“规划”就跳过规则基线。

下一版本应加入与生成模板不同的人工改写、跨句约束、隐式单位、冲突优先级和语义正确但
内容错误的工具返回。只有冻结这些任务和推翻条件后，才运行 LangGraph。
