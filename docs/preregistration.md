# 直接调用基线预注册 v1

- 假设：版本化 Schema 加确定性工具可以为后续 Agent 对比提供无歧义 Oracle。
- 唯一主指标：任务级 `status + answer` 精确匹配率。
- 次指标：合法任务成功率、无效任务正确拒绝率、平均工具调用数。
- 推翻条件：任一冻结任务重复运行结果不同，或直接调用未达到 100% 精确匹配。
- 当前样本量：契约开发用种子集；不作统计显著性结论。
- 冻结规则：生成产物记录任务文件 SHA-256、Python/OS、运行时间和 git SHA。
- 后续比较：LangGraph 与自研 Runtime 使用相同任务、工具、最大步数和评分器；
  Oracle 结果不与随机 Agent 的 pass rate 混写。
