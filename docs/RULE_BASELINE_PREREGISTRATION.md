# 规则解析基线预注册 v1

- 状态：在正式留档运行前冻结；此前仅做实现调试，不保留调试产物。
- 假设：规则解析器能处理当前受控模板，但其成功不代表开放式自然语言泛化。
- 唯一主指标：隐藏结构化 `operation + inputs` 的完全解析一致率。
- 次指标：最终任务契约通过率，以及按 split/level 分层的两项指标。
- 推翻条件：解析一致率低于 100%，说明生成模板与规则契约存在实现缺口；
  即使达到 100%，也不能支持“需要 Agent”的结论。
- 样本量：120 条 development 任务；train/dev/test 各 40 条。
- 公平边界：解析器只能读取 `request`、`task_id` 和 `level`，不得读取隐藏
  `operation`、`inputs` 或 `expected`。
- 后续门禁：只有加入真正多步约束、信息缺失追问和工具失败恢复任务后，才冻结
  最终 test；本轮的 `test` 仅验证模板隔离机制。
