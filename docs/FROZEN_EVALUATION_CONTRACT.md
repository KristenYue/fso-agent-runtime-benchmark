## 公平比较要求

1. LangGraph 与自研 Runtime 不得读取隐藏 `inputs` 和 `expected`；
2. 只把自然语言 `request`、允许的工具 Schema 和运行策略交给系统；
3. LLM 不得直接生成 BER 或阈值作为地面真值，所有数值必须来自工具；
4. 不得为测试集新增专用正则、few-shot 示例或任务 ID 分支；
5. Prompt、模型快照、温度、超时、重试、最大步数和工具权限必须写入 manifest；
6. 测试集只运行最终配置；调试和选择使用 development 数据；
7. 保留全部失败轨迹，不因结果较差更换指标或删除任务。

正式运行由 `scripts/run_langgraph_model_challenge_once.py` 执行。它要求 development
manifest、完全相同的模型/端点、显式批准值和空运行账本；开始调用前写入 `running`
账本，即使中途失败也不得重新选择配置或静默重跑。
