# 多步规划非 Agent 基线预注册 v2

- 状态：正式留档运行前冻结；此前只运行代码测试与生成器校验。
- 数据：`tasks-v2-development` 共 150 条，其中 30 条五步规划任务；每个 split 10 条。
- 基线：隐藏结构化输入的直接 Oracle；仅读取请求文本的规则解析 + 同一确定性工作流。
- 唯一主指标：任务级 `status + answer` 契约通过率。
- 次指标：约束违反率、平均 optimality gap、平均工具调用数、首次超时恢复率、
  澄清准确率、重复成功步骤和过早停止数。
- 推翻条件：任一非 Agent 基线未达到 100% 任务契约通过，或出现约束违反、
  非零 optimality gap、恢复失败、错误澄清、重复成功步骤或过早停止。
- 失败口径：缺少 Rytov/目标 BER/功率上限时必须 `needs_clarification`；
  两次目录不可用必须 `tool_error`；数据充分但无已验证可行配置必须
  `no_feasible_solution`，三者不得混用。
- 局限：30 条请求仍来自受控模板。即使规则基线达到 100%，也只证明该模板无需 Agent；
  最终冻结前还需加入未见改写和更丰富的冲突/恢复任务。
