# Offline Stability / Soak Test Report

## Scope

This is a deterministic, no-model, no-network Runtime scheduling test. It does
not measure end-to-end Agent latency and does not establish an online SLA.

Evidence: `artifacts/qa/stability_5000.json`, generated by
`scripts/run_stability_test.py`.

## Memory interpretation

The script keeps only a bounded 512-entry latency sample and forces collection at
each checkpoint so its own reporting storage cannot grow with 5,000 runs. Current
tracked allocations were 49,068 bytes at 500 runs and 54,933 bytes at 5,000 runs;
the later checkpoints increase only slightly rather than linearly with runs.
This is a lightweight local signal, not a leak proof or process-RSS benchmark.

## Verdict

**PASS WITH KNOWN LIMITATIONS.** The pass criterion was met for deterministic
behaviour, expected terminal states and trace completeness. It does not cover
real LLM long-running calls, GUI, high concurrency, distributed workers or
production traffic.
